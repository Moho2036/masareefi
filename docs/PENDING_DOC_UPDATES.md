# قائمة التحديثات التوثيقية المعلقة (Pending Documentation Updates)

### بروتوكول تنفيذ المزامنة الدائم (يُطبّق حرفياً عند أمر المستخدم "نفّذ مزامنة التوثيق")
1. **التحقق من الكود أولاً:** اقرأ البنود المعلقة أسفل هذا البروتوكول، ثم افتح الملفات البرمجية الفعلية المرتبطة بكل بند للتأكد من دقة التغيير قبل تعديل أي وثيقة.
2. **تحديث المسار التقني (`docs/PROJECT_BIBLE.md`):** طبّق التحديث بأسلوب **الحالة الراهنة فقط (State-Based)** و**الاستبدال الجراحي لا الإلحاق (Replace, Never Append)**؛ يُحظر كتابة عبارات تاريخية ("سابقاً كان..." / "تم تعديل...") أو لصق كود خام طويل أو تكرار ما يوجد في `DESIGN_SYSTEM.md` و `AGENTS.md`.
3. **تحديث المسار البشري (`docs/human/`):** راجع `docs/human/00_خريطة_الصيانة_الداخلية.md` وحدّث الملفات البشرية المتأثرة فقط (الأدلة العميقة أولاً، ثم التحقق هل يحتاج الموجز أو الصفحة الواحدة أو الأسئلة الشائعة لتعديل موازٍ). **شرط صارم:** لغة عربية بشرية 100% خالية تماماً من أي مصطلح برمجي أو أسماء ملفات أو دوال.
4. **التنظيف والتقرير:** بعد اكتمال التحديث ومراجعة التطابق بين المسارين، امسح البنود المنفّذة فقط من قسم "التحديثات المعلقة" أسفل هذا البروتوكول وأعده إلى `لا توجد تحديثات معلقة حالياً` (مع الحفاظ على هذا البروتوكول في الأعلى دون مساس)، ثم قدّم للمستخدم ملخصاً من سطور قليلة بما تم تحديثه في كل ملف.
